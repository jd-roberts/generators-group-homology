# Prime-7 relation-module spanning: criterion, small tests, and a bounded pilot

**Subsequent authorized execution:** the [first pilot report](PRIME7-PILOT-1-RESULTS.md)
records the passing OS safety gate and exactly one bounded run. It found
no new certificates; the certified total remains five of 32. The text below
records the earlier preparation and proposal, not authorization for another
run. Full spanning remains unresolved.

This report prepares a certificate of **spanning**, without asserting
independence, nontriviality or dimension six. No prime-7 proof search or
Knuth–Bendix completion was launched. The prime-7 work here consists of
replaying existing certificates, finite-field linear algebra and explicit
algebraic composition of five immediate certificates.

## 2. Exact spanning criterion and proof

Let R=(R1,...,R32), N=normal_closure_F(R), p=7, S=(s1,...,s12) the
b0-interpreted candidates, and `H0=[F,N]N^7`. Define

```
B = normal_closure_F( [xi,Rj], Rj^7, sk :
                     i=1,...,6; j=1,...,32; k=1,...,12 ),
Q = F/B.
```

Use the GAP commutator convention `[x,r]=x^-1*r^-1*x*r`; changing to the
opposite convention would generate the same normal subgroup, but the
stored certificate words and indices use this convention exactly.

**Lemma:** the normal closure of `[xi,Rj]` and `Rj^7` is H0. One inclusion
is immediate. For the reverse inclusion, in the quotient by these finitely
many words, every Rj commutes with every free generator. Thus all conjugates
of Rj equal Rj, and the image of N is an abelian group generated by the
images of Rj, each of exponent dividing seven. Consequently all `[F,N]`
and every seventh power of every element of N vanish. This proves equality;
there is no need to enumerate infinitely many seventh powers.

Because each sk belongs to N, B is contained in N. In F/H0 the image of N
is central and elementary abelian, so normal closure of S inside F/H0 is
just its F7-linear span. Hence

```
N/B = A/span(S),      A=N/H0.
```

Since R normally generates N, the images of **all 32 defining relators
span A**. Therefore the following are equivalent:

1. The twelve candidates span A.
2. Each of the 32 classes [Rj] lies in their span.
3. Each Rj belongs to B.
4. All 32 Rj are identity words in the SAME fixed quotient Q.

This is an exact criterion, not a heuristic or an independence test.
**Do not include Rj themselves as defining relations of Q.** That would
force all tests to pass without proving anything. Q still surjects onto
the original group; it need not be finite even if its central kernel is small.

If the criterion is established, the already verified invertible auxiliary
exponent matrix and split-kernel calculation show the six valid corrected
classes span H2 of the presented group. They may be dependent or all zero.
Identification with the intended arithmetic matrix group uses the external
presentation theorem/hypotheses separately documented in the source audit.

## 3. Implemented certificate-producing method

[experiments/relation_span.py](../experiments/relation_span.py) constructs Q
once, retaining a stable label for every relation. It builds one finite
index of valid cyclic-relator splits, with shorter input relations first.
No new completion equations are derived and no KBMAG is loaded. If a
cyclic conjugate of a defining relation is L*T, the indexed rule replaces
L by T^-1 and retains the conjugator, defining-relation index and sign.

If W=P*L*U is replaced by W'=P*T^-1*U, then `W*(W')^-1` is precisely the
recorded conjugate of a defining relation. Composing these identities
until the final free word is empty produces a product of conjugates for W.
A bounded breadth-first search allows modest length increases; it is not
complete and does not claim to produce canonical normal forms.

The same fixed index is used for all defining-relator tests. The default
limits are five seconds **shared by building the index and all targets**,
10,000 indexed rule instances, 3,000 states per target and word-length
growth at most six. The code guards against increasing the time beyond
five seconds, rules beyond 20,000, or states beyond 10,000. A partial index
is still sound; it may simply prove fewer identities.

The separate [checker](../scripts/check-relation-span-certificate.py) imports
no producer code. It independently constructs the precise quotient,
checks candidate membership in N, and verifies each claimed product by
free cancellation. Candidate membership is a mandatory hypothesis: merely
killing words outside N cannot establish the requested relation-module result.
The checker also validates optional finite permutation obstructions.

| Outcome | Interpretation |
| --- | --- |
| Independently checked product of conjugates | Rigorous positive identity certificate |
| Identity from sound nonconfluent rewriting | Valid positive result; for this reproducibility standard also retain/verify its derivation |
| Time/rule/state limit, exhausted finite search, or a nonidentity output without confluence | Unresolved; no nonmembership inference |
| A verified homomorphism out of Q with nonidentity target image | Rigorous nonmembership obstruction, hence failure of this candidate spanning list |

KBMAG's usual reduced-word output does not by itself supply products of
conjugates. A future KBMAG adapter must retain independently checkable
proofs of its rules/identity derivations before its results meet the
certificate standard used here. This adapter is not implemented or tested.
The original GAP functions and their options remain unchanged.

## 4. Small cases, mathematical controls, and measurements

The ten exact fixtures are in
[relation-span-small.json](../tests/fixtures/relation-span-small.json).
For a finite cyclic group Cm, positive-degree mod-p H1 and H2 have dimension
one when p divides m and zero otherwise, by the cyclic periodic resolution.
Kunneth gives dim H2(C2 x C2;F2)=3. A free group's H2 is zero.

The original functions run only on this small whitelist, starting with their
full defining-relator list. All controls give the expected bounds. The new
candidate-size bound `a+|S|-t` is reported **only after spanning is certified**,
where a is the Tor dimension and t the integer relator-lattice rank.
In every positive test it matches the original bound and known dimension.
No candidate-size bound is accepted for any nonspanning test.

The missing-candidate cyclic tests have exact cyclic permutation obstructions.
The missing-commutator C2 x C2 test uses the regular permutation action of
the order-eight upper-unitriangular group over F2: squares vanish, but the
central commutator survives. The same fixed quotient kills the proposed
squares, so this proves nonspanning rather than merely failing to find a proof.
Notably, C3 at p=2 has H2=0 while an empty list still fails to span A.
Zero homology is not a replacement for the spanning premise.

Four additional acceptance checks reject a corrupted product, missing
candidate membership and a vacuous quotient with raw R inserted; a state-limit
experiment on a true positive remains unresolved. The complete small fixture
suite has no implication that the arithmetic computations are inexpensive.

## 6. What existing identities can safely save

In A, conjugation disappears. For any exact candidate membership product,
counting signed occurrences of the original Rj gives its coordinates in
the free vector space F7^32 mapping onto A. This produces a 12x32 matrix M.
These are not necessarily unique coordinates in A: identities among the
relators can identify different vectors.

Existing presentation-map certificates give certified zero rows as well.
Let U be the 64x32 occurrence matrix for forward relator certificates and
V the 32x64 matrix for reverse relator certificates. Since phi*psi is the
identity on F6 as a free-group map, every row of `I32 - V*U` maps to zero
in A. Similarly, forwarding each of the fourteen certified generator
defects gives a free identity and a zero occurrence row. These 46 rows
form a matrix Z. This construction uses identities whose free-word proofs
were already independently verified; it does not assume any spanning result.

Exact F7 linear algebra gives

```
rank(M)=12,   rank(Z)=5,   rank([M;Z])=17.
```

Only coordinate targets 3,5,9,12,15 are in that combined row span. For
example, its seventeenth zero row is `2*e12`, and the fourth candidate row
is `e9 + 5*e12 + e15`. This agrees with the two elementary Q-certificates
above. The other relations can be useful jointly without certifying any
additional individual target yet.

A length-ordered complement to these 17 established row directions is

```
R1, R2, R4, R6, R7, R8, R10, R11, R13, R14,
R18, R26, R28, R29, R30.
```

**If these fifteen future targets are all certified in span(S), all 32
are in span(S).** The inventory includes explicit row-combination witnesses
expressing every e_j using M, Z and these fifteen unit vectors. The latter
are clearly labelled **unproved hypotheses**, not stored as established
zero relations. Thus the reduction to fifteen tests is a proved sufficiency
statement, not a completed spanning proof. One can instead attempt all
27 unresolved targets if that is more effective. A failure of this selected
search order says nothing about the truth of spanning.

[check-prime7-spanning-inventory.py](../scripts/check-prime7-spanning-inventory.py)
independently replays the source certificate verifier, reconstructs M and Z,
checks the ranks and every row-combination witness, and checks the five
explicit Q-products. The residual formal dimension 15 is **not** a lower
bound on A/span(S), nor an obstruction to spanning; additional identities
may collapse it completely.

Safe reuse is limited to the same input words, coefficient prime and
quotient, with original relation indices or verified reindexing. Rules
from F/N cannot be imported into Q: the original Rj are not relations
of Q. Likewise, positive rules proved in a stronger quotient formed by
killing extra candidates need not hold in the present weaker quotient.
Existing N-membership certificates are reused as exact identities and
then translated with their justification, as in R15. Any new equation
used by the proof search must have a verified Q-derivation.

The earlier SL(2,F29) assignment from the membership investigation kills
every original Rj, so it supplies no nonspanning obstruction for this new
test. Such an obstruction would have to satisfy the auxiliary Q relations
while keeping at least one Rj nonidentity.

from an unimplemented KBMAG proof-tracing adapter.

immediate Q-certificates. Check source and blueprint hashes. Allow at most
12 seconds for the existing source verifier, whose GAP stage itself has a

construction and the selected fifteen targets, at most 20,000 indexed
rule instances, 1,000 states per target, and length growth at most six.

first, retaining their stable original indices. Use a 512 MiB per-process

launcher requirements; the existing small-test runner does not implement

## 8. Assessment and precise remaining claims

A fixed quotient offers a potential benefit: reuse one sound rule index or
completion, and certify a small final set directly instead of rebuilding
systems after each greedy deletion. Existing exact identities already reduce
a sufficient future target set to fifteen. Neither fact establishes a
runtime improvement. The final-candidate quotient imposes fewer killing
relations than many FindBasis deletion tests and can be substantially harder.
The arithmetic group remains an infinite quotient of Q; finite small-group
examples and startup-dominated timings cannot predict its completion cost.
Proof recording can add substantial memory and runtime overhead.

The installed KBMAG interface does not currently provide the independently
checked derivations this project requires. Consequently the implemented
finite proof search is useful as a bounded, auditable first experiment,
not an evidenced replacement for a multi-day calculation. The proposed
approach's arithmetic effectiveness is **unmeasured**.

There is a concrete limitation of the initial finite search: growth by six
letters and near-half cyclic splits prevent many long seventh-power words
from participating in short-target paths. A successful larger calculation
may need certified algebraic collection or a proof-producing completion;
merely increasing the number of targets attempted does not resolve that.

Established algebraically: the finite criterion, its equivalence with
spanning, the split-kernel implication and the sufficiency of the future
target set once its tests pass. Established by replayable certificates:
the source maps/membership, ten small controls, five Q-target products,
and the exact finite-field witness calculations. Still unverified: all
remaining arithmetic target identities and full spanning. The historical
assertion remains a source claim whose exact run coordinates are unrecovered.
No nontriviality, independence, new arithmetic theorem or measured speedup
is claimed. The six valid corrected classes retain their already certified
membership/kernel status regardless of whether spanning is later proved.
