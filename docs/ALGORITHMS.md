# Reading the homology algorithms

This describes `Algorithms.g` at the original research revision
`f684175285d780752f56d1baf6d0bf5f7d87ef33`. The implementation is unchanged.
Function names below refer to that file. The interpretation of bounds assumes
valid presentations, a prime coefficient, and the spanning condition below.

## Objects and conventions

Write `F` for a finitely generated free group, `L` for the finite list of
defining relator words, `N` for their **normal closure** in `F`, and `G=F/N`.
The code calls the list `Relators`; it is not itself a normal subgroup.
Write `q` for the coefficient prime. This separates it from the prime used to
label the arithmetic presentations `G3`, `G5`, `G7`, and `G11`.

All words supplied to a function must belong to the same free group.
`AbelianInvariants` uses `0` for an infinite cyclic summand and positive
integers for finite cyclic factors. GAP's `Comm(x,y)` is `x^-1*y^-1*x*y`;
some literal commutators in the library use the other common convention.
Keep the recorded words, generator ordering, and presentations when reproducing
runs; equivalent presentations can behave very differently computationally.

## Presentation helpers

| Function | Procedure | Actual return value |
| --- | --- | --- |
| `PresentationOfFiniteGroup(H)` | Coset-table presentation, `TzGoGo` Tietze simplification, conversion to an fp group | `[group, freeGroup, relators]` |
| `PresentationOfFpGroup(G)` | `IsomorphismSimplifiedFpGroup`, then extract its range and presentation | `[isomorphism, group, freeGroup, relators]` |

The second function returns **four** fields, despite its three-field header
comment. Retain its isomorphism to transport words back to the original group.
Neither helper computes homology. Coset enumeration and Tietze simplification
can themselves dominate a run; a shorter presentation is not necessarily an
easier completion problem.

## Abelian calculations

Each of these calls `AbelianInvariants(F/L)`:

| Function | Computed quantity |
| --- | --- |
| `FirstHomologyCoefficients(F,L,q)` | Number of zero factors plus finite factors divisible by `q`, hence `dim H1(G; F_q)` |
| `Tor(F,L,q)` | Number of nonzero factors divisible by `q`, hence `dim Tor(H1(G; Z), F_q)` |
| `PrimePrimaryRank(F,L,q)` | Sum of `q`-adic valuations of nonzero finite factors; the logarithm base `q` of the order of the finite `q`-primary torsion subgroup |

The last quantity is **not** the number of cyclic factors or an F_q dimension:
`C9` gives valuation 2 at `q=3` but dimension 1 after tensoring. Free factors
contribute to H1 but not to `Tor` or `PrimePrimaryRank`. H1 is computed from
the abelianization for every group, not only when `G` itself is abelian.

Equivalently, construct the integer matrix of exponent sums of the relators
in the free generators and compute its Smith normal form. This is a useful
independent route for future validation and optimization.

## Word reduction in a central elementary-abelian relation quotient

`Reduce_Word(F,L,w,S,q)` constructs

```
Q_S = F / < [x,r], r^q, s : x a free generator, r in L, s in S >^normal.
```

It creates a new KBMAG rewriting system, sets options, runs `MakeConfluent`,
and returns `ReducedWord(system,w)`. The commutators centralize the image of
`N`; the powers make that image have exponent dividing `q`. Thus

```
E = N / ([F,N] N^q)
```

is a finite-dimensional F_q vector space, generated by the images of `L`.
For words in `N`, reduction in `Q_S` tests whether their classes are in the
span of the classes of `S` in `E`.

The routine discards the completion return value and the rewriting system.
KBMAG can stop without confluence and still provide reduction rules. A
reduction to the identity certifies equality using those rules. A nonidentity
reduction without confluence is **inconclusive**; it does not certify linear
independence. Errors, missing binaries, and externally killed runs are failed
or unfinished computations, not mathematical answers.

## Greedy elimination

`FindBasis(F,L,q,S)` starts with `Gen=S`. For each candidate `x`, it reduces
`x` with `Difference(Gen,[x])` killed in the quotient. If the result is the
identity, it removes `x`; otherwise it retains it. It returns

```
[remainingCandidates, numberRemaining, reductionsInOriginalCandidateOrder]
```

The third field corresponds to the original loop order, including deleted
candidates; it does not index just the final survivors. `Difference` is GAP's
set difference, so its ordering and handling of duplicates matter for exact
run reproduction. `Gen:=S` does not itself copy a list, but subsequent
deletions rebind `Gen` rather than mutating `S` in place.

With complete equality decisions and a spanning input, this is basis
extraction. With incomplete reductions it gives a possibly redundant
spanning set and therefore an upper bound. The safe default is `S=L`.
A smaller `S` requires a proof that its images still span **all of E**.
Passing an arbitrary subset, or `[]`, is not justified merely because the
function accepts it. The library's global `comm` is a particular list of
31 words for `G7`; it is not a certified replacement for `k7`.

The survivors are words spanning the relation quotient, **not automatically
an explicit basis of H2**. Extracting H2 generators requires the kernel of
the exponent-sum map and, for field coefficients, accounting for the Tor
term. The current return values contain no chain-level cycles or proof
certificates.

## The second-homology bound

`SecondHomologyCoefficients(F,L,q,S)` evaluates:

```
a = Tor(F,L,q)
b = PrimePrimaryRank(F,L plus all generator commutators,q)
c = PrimePrimaryRank(F,[r^q : r in L] plus all generator commutators,q)
e = FindBasis(F,L,q,S)
d = a + b - c + e[2]
return [e[1],d,e[3]]
```

Here is why this is a bound, rather than just a numerical formula. Let `M`
be the subgroup of `F_ab = Z^n` generated by the exponent-sum vectors of
`L`, of rank `t`. The integral Hopf exact sequence identifies

```
0 -> H2(G; Z) -> N/[F,N] -> M -> 0.
```

Since `M` is free abelian, tensoring with F_q gives
`dim(H2(G; Z) tensor F_q) = dim E - t`. The universal coefficient theorem
then adds the Tor contribution `a`. The abelian quotients in `b` and `c`
are `Z^n/M` and `Z^n/qM`. Smith normal form shows `c-b=t`, including when
these quotients have free factors. Therefore

```
dim H2(G; F_q) = a + dim E - t <= a + e[2] - t = d.
```

This interpretation depends on the spanning condition for `S`. A positive
upper bound does not establish nonvanishing, dimension equality, or an
independent generating family. A justified zero bound establishes vanishing.
A negative answer would signal invalid inputs, an unjustified subset, or a
defect requiring investigation; it must not be reported as a dimension.

## Standard and large variants

| Path | `maxeqns` | Field written by the existing code |
| --- | --- | --- |
| `Reduce_Word` / `FindBasis` / `SecondHomologyCoefficients` | 500,000 | `tindyint := 100` |
| `Reduce_Word2ndHom_large` / `FindBasis2ndHom_large` / `SecondHomologyCoefficients_large` | 10,000,000 | `tindyint := 1000` |

KBMAG 1.6.1 reads **`tidyint`**, not `tindyint`. Its manual explicitly warns
that misspelled option fields have no effect. Inspection of its
`WriteOptionsRWS` confirms that only `tidyint` is serialized to the external
program. Consequently the intended tidy-interval change is not effective
in this environment; the large path increases the equation cap but does
not implement a new mathematical method. This finding is documented, not
fixed, to preserve the original execution path.
